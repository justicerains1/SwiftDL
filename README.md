# SwiftDL

极简、高性能的 Windows 多线程下载器（Rust + egui，单个 exe）。

## 特性
- **多连接分段下载**：稀疏预分配（NTFS 不必先补零），每个连接按偏移直接写入（`seek_write`，无锁），1 MiB 写缓冲
- **动态分段**：连接空闲时自动把剩余最多的分段对半拆开接手，不会被慢分段拖尾
- **稳定性**：单个分段失败只交给其他连接接手；遇到 429/503 自动降低并发、平稳后恢复；连接停滞 15 秒自动重连；403/404 快速失败并提示更新链接
- **断点续传**：每秒保存进度；退出或崩溃后重新打开自动续传，并用 ETag/大小校验文件是否变化
- **队列与限速**：最大同时任务数、全局令牌桶限速、队列上移/下移/移到队首、出错自动重试
- **任务管理**：更新失效链接后断点续传、重复链接提示、按队列/名称/大小/状态排序、SHA-256 校验
- **计划任务**：指定每日开始/停止时间；全部完成后退出、睡眠或关机（60 秒可取消）
- **按类型分类保存**：压缩文件、视频、音乐、文档、程序、镜像文件、图片自动存入对应子目录
- **系统托盘**：关闭窗口后台继续下载，可开机自启动
- **剪贴板监听**：复制下载链接后自动弹出新建窗口（扩展名可配置）
- **网页媒体嗅探**：扩展自动发现网页中的视频、音频与 m3u8 流媒体，图标显示数量，弹窗选择清晰度一键下载；网页视频上悬停出现“下载此视频”按钮
- **HLS（m3u8）下载**：解析主列表与清晰度、分片多线程下载、AES-128 解密、断点续传；fMP4 直接保存为 .mp4，TS 在有 ffmpeg 时无损转为 .mp4（否则保存为 .ts）。不支持 DRM 加密视频与直播流
- **浏览器接管**：Chrome/Edge 扩展拦截下载，带上 Cookie/Referer；SwiftDL 未运行时交回浏览器下载。首次启动有安装向导：自动打开浏览器扩展页并定位扩展文件夹，装好后自动识别
- **定期清缓存**：每 30 分钟清理孤立的 `.swdl` 临时文件、过期的已完成记录（默认 30 天）；设置里也可手动立即清理
- **代理**：留空 = 系统代理，`direct` = 直连，或填写 `http://127.0.0.1:10808` / `socks5://…`
- **单实例**：`swiftdl.exe <url>` 会把链接交给已在运行的窗口
- **现代界面**：侧边栏分类与计数、卡片式任务列表（悬停快捷操作）、分段图详情、60 秒速度折线、完成提示；浅色/深色/跟随系统主题
- **图标零字体依赖**：所有图标均为矢量绘制，文件类型徽标只用 ASCII，任何系统上都不会显示成方框（有单元测试守护）

## 快捷键
| 按键 | 作用 |
|---|---|
| Ctrl+N | 新建下载 |
| Ctrl+V | 在主界面直接粘贴链接 |
| Ctrl+F | 搜索任务（Esc 清空） |
| Ctrl+Enter / Enter | 在新建窗口中开始下载 |
| Space | 开始/暂停选中任务 |
| Delete | 删除选中任务 |
| Ctrl+A | 全选 |
| 双击 | 打开已完成文件；未完成则切换开始/暂停 |

## 构建
需要 Rust（GNU 工具链）和 MinGW-w64：

```sh
. ./env.sh                     # 设置 RUSTUP_HOME / CARGO_HOME / PATH（含 MinGW），路径按本机修改
cargo build --release          # 产物：target/release/swiftdl.exe
cargo test --release -- --test-threads=1
node --test extension/tests       # 扩展嗅探逻辑与后台流程测试
python -I packaging/package.py # 打包：dist/SwiftDL-v<版本>-windows-x64.zip
```

## 安装浏览器扩展
首次启动 SwiftDL 会弹出安装向导（之后可在 设置 → 剪贴板与浏览器 → 安装向导 再次打开）：
1. 点击“在 Edge 中安装”或“在 Chrome 中安装”，程序会打开浏览器扩展页，并在资源管理器中选中扩展文件夹（路径已复制）
2. 在扩展页开启“开发者模式”，把文件夹拖进去（或点“加载解压缩的扩展”粘贴路径）
3. 扩展连接后向导自动显示“安装完成”

Chrome/Edge 不允许程序静默安装商店之外的扩展，所以最后一步需要用户本人确认。扩展图标弹窗中可开关接管、设置最小文件大小和端口（默认 52080）。

## 数据位置
`%APPDATA%\swiftdl\settings.json`、`tasks.json`；下载中的临时文件为 `<文件名>.swdl`，与目标文件放在同一目录。
