SwiftDL —— 极简高性能多线程下载器
====================================

【运行】
  双击 SwiftDL.exe 即可，无需安装。
  系统要求：Windows 10 / 11 / Server 2019 及以上（64 位）。

【添加下载】
  · 点击“新建下载”，或按 Ctrl+N
  · 在主界面直接按 Ctrl+V 粘贴下载链接
  · 复制下载链接（zip、exe、mp4 等）后会自动弹出新建窗口
  · 安装浏览器扩展后，浏览器里的下载会自动交给 SwiftDL

【安装浏览器扩展（Chrome / Edge）】
  首次运行会自动弹出安装向导：
  1. 点击“在 Edge 中安装”或“在 Chrome 中安装”
  2. 在打开的扩展页面中开启“开发者模式”
  3. 把资源管理器里已选中的 extension 文件夹拖到扩展页面上
  安装后向导会自动显示“安装完成”。以后可在 设置 → 安装向导 中再次打开。
  提示：SwiftDL 未运行时，下载会自动交还给浏览器。

【下载网页视频（嗅探）】
  · 安装浏览器扩展后播放网页视频，扩展图标会显示发现的资源数量
  · 点击扩展图标，在“本页媒体”中选择清晰度并点“下载”
  · 或把鼠标移到网页视频上，点右上角的“下载此视频”按钮
  · m3u8 流媒体会自动合并；电脑装有 ffmpeg 时保存为 .mp4，否则为 .ts（可正常播放）
  · 受 DRM 保护的视频（如部分付费平台）和直播流无法下载

【后台运行与计划任务】
  · 关闭窗口后程序在系统托盘继续下载，单击托盘图标恢复窗口，右键可退出
  · 新建下载时选择“计划下载”，到设置中的计划时间自动开始
  · 侧边栏“全部完成后”可选择退出、睡眠或关机（执行前有 60 秒可取消）
  · 链接过期时，右键任务选择“更新下载链接”，粘贴新链接即可继续

【新功能（v0.4）】
  · 浏览器扩展需要“配对”：通过安装向导加载的扩展会自动配对；
    手动加载的扩展，请在 SwiftDL 设置 → 安全与隐私 复制配对令牌，粘贴到扩展弹窗
  · 可直接把浏览器中的链接、文本或 .txt 链接列表拖到窗口
  · 窗口在托盘时，下载完成会弹出 Windows 系统通知；任务栏图标显示总进度
  · 有新版本时会提示，一键更新（自动校验文件完整性）
  · 设置 → 常规 → 语言 可切换 English

【FTP / SFTP / BT（v0.5）】
  · 粘贴 ftp://、ftps://、sftp:// 链接，在新建窗口填写用户名和密码（密码加密保存）
  · 粘贴磁力链接，或把 .torrent 文件拖到窗口；可勾选只下载部分文件
  · 设置 → BT / 磁力：端口、做种、上传限速、关联磁力链接与 .torrent 文件

【证书不可信的站点（v0.5.1）】
  · 内网、自签名或证书过期的 HTTPS / FTPS 站点会提示“服务器证书不可信”
  · 确认站点可信后，点任务详情或右键菜单中的“信任此站点并重试”即可下载；
    新建窗口里也可直接点“信任此站点”
  · 已信任的站点在 设置 → 网络 → 信任的站点 中查看或取消

【打开已下载的文件（v0.5.2）】
  · 双击已完成的任务，用电脑上该类型文件的默认程序打开（如压缩包用 7-Zip / WinRAR）
  · 没有可用的程序时会弹出“打开方式”，选择程序即可，可勾选“始终使用此应用”
  · 右键“选择打开方式”可换用其他程序打开

【日志与问题反馈（v0.6）】
  · 设置 → 存储与缓存 → 打开日志目录，反馈问题时请附上当天的日志
    （日志中的链接已去除账号、密码和参数）
  · 程序异常退出后，下次启动顶部会提示，点“查看报告”可找到诊断报告
  · 升级后浏览器扩展会自动重新加载；如扩展弹窗提示版本不一致，
    请在浏览器扩展页点击 SwiftDL 的“重新加载”

【清空历史下载（v0.7）】
  · 任务列表标题栏右侧的“清空历史”，或 设置 → 存储与缓存 → “清空历史下载”
  · 移除所有已完成的任务记录；确认框中可选择是否包含出错的任务
    （其已下载的部分会被删除）、是否同时删除已下载的文件（默认保留）
  · 正在下载、排队和已暂停的任务不受影响

【常用快捷键】
  Ctrl+N 新建下载    Ctrl+V 粘贴链接    Ctrl+F 搜索
  Space 开始/暂停    Delete 删除        Ctrl+A 全选
  双击已完成任务可直接打开文件

【设置】
  点击右上角齿轮图标：默认保存目录、每任务连接数、同时下载数、
  全局限速、代理（留空=系统代理）、主题（跟随系统/浅色/深色）等。

【数据位置】
  配置与任务库：%APPDATA%\swiftdl\（settings.json、swiftdl.db）
  下载中的临时文件：<文件名>.swdl（与目标文件在同一目录，完成后自动改名）

【自动更新下载失败】
  · 程序会自动在 GitHub 与加速线路之间切换，并从断点继续下载
  · 仍然失败时：可在 设置 → 网络 中配置代理后点“重试”；
    或点“在浏览器中下载”，下载好安装包后点“从本地文件安装”选中它
    （安装前同样会校验 SHA-256，不会装上被篡改的文件）

【卸载】
  1. 设置 → 存储与缓存 → “清除所有软件数据”，确认后程序退出并删除
     设置、任务记录、日志、临时文件以及开机自启动、文件关联等注册表项
     （已下载完成的文件不会删除）
  2. 在浏览器扩展管理页移除 SwiftDL 扩展
  3. 删除程序所在文件夹即可
